# CertBypass IPS Patch para Stardew Valley (Nintendo Switch)

Este parche IPS32 deshabilita la verificación estricta de certificados SSL/TLS y el pinning de certificados de Nintendo dentro del binario del juego, permitiendo que se conecte a servidores Nextendo NPLN locales o personalizados mediante TLS con certificados autofirmados.

## Metadatos
- **Juego:** Stardew Valley
- **Title ID:** `0100E65002BB8000`
- **Versión comprobada:** v1.6.15.13 (Update v1310720)
- **Build ID del ejecutable (`main`):** `E7F845093E8CBC68DACF011CCB620D6667B5A20B`

## Instalación en Ryujinx
Copiar el archivo `.ips` en:
```text
portable/mods/contents/0100E65002BB8000/exefs/
```
o en:
```text
portable/sdcard/atmosphere/contents/0100E65002BB8000/exefs/
```

## Instalación en Consola (Atmosphère)
Copiar el archivo `.ips` en la tarjeta SD de la consola:
```text
sdmc:/atmosphere/contents/0100E65002BB8000/exefs/
```
